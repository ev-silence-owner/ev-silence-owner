### What this is

An umbrella for **System Silence** — a set of contracts that protect attention and perception in interfaces.
Timing derives from one root token (**1618 ms**), proportions from φ, surfaces from a measured graphite ladder.
Gold appears once.

Public materials are **non‑clinical**. They do not diagnose, treat, or predict a medical or mental state.

<br>

### Principles

| | |
|:--|:--|
| **φ‑derived time** | Every duration is a power of φ from 1618 ms. No magic numbers. |
| **Zero‑PII by design** | No identifiers, no biosignal capture, no accounts. |
| **Neurodiversity‑first** | `prefers-reduced-motion` honoured · WCAG 2.2 AA · no pure black, no pure white. |
| **S11 language** | *pattern · signal · observation* — never *disorder · symptom · diagnosis*. |
| **Deterministic** | Same seed, same result. Reproducible by anyone. |
